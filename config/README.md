# Audio visualizer config

`audio_viz.json` holds your tuned LED audio settings (colors, smoothing, layout).

- **Backup:** copy this file, e.g. `audio_viz.backup.json`
- **Restore:** replace `audio_viz.json` with your backup and restart the app
- **Edit:** change values while the app is stopped; invalid JSON will fall back to code defaults

The app loads `config/audio_viz.json` automatically on startup.
